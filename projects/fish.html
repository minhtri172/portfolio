Cloud-Native Web Application

Fish Sharing

Fish Sharing is a scalable, user-friendly web platform designed to help people share and explore fish-related content in a reliable cloud environment. The project emphasizes high availability, automated deployment, and secure access through modern AWS services.

Live Demo Back to Portfolio

Project Overview

This project focuses on building a resilient web application architecture that can scale smoothly as demand grows. It demonstrates how to combine frontend delivery, backend hosting, storage, and automation to create a production-style system.

  • Designed and deployed a web application with strong reliability and availability.
  • Integrated cloud-native services for content delivery, storage, and automation.
  • Improved application performance and resilience with load balancing and autoscaling.
  • Implemented secure HTTPS delivery and route management for a polished user experience.

Key Features

  • Highly available application infrastructure using EC2, Nginx, an Application Load Balancer, and Auto Scaling Groups.
  • Continuous deployment pipeline with CodePipeline and CodeDeploy to streamline delivery.
  • Cloud storage and persistence with S3 and DynamoDB.
  • Serverless scaling support using Lambda and CloudWatch scheduling to reduce unnecessary cost.
  • Secure, optimized delivery through Route 53, CloudFront, and ACM.
