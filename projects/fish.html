Fish Sharing

A community web application for sharing and exploring fishing catches. The project combines a responsive web experience with AWS infrastructure designed for reliable delivery and scaling.

View live demo ↗ Back to portfolio

Project overview

Fish Sharing is a web platform where people can share and explore fishing content. The project also demonstrates how to deliver a web application through AWS services, with load balancing, autoscaling, automated deployments, and secure content delivery.

Architecture

The AWS architecture combines EC2 application servers with a load balancer and Auto Scaling group, while cloud services support delivery, storage, deployment automation, and monitoring.

Key features

  • Community interface for browsing and sharing fishing catches.
  • EC2 application servers behind a load balancer with Auto Scaling.
  • Automated deployment using CodePipeline and CodeDeploy.
  • Route 53, CloudFront, and ACM support domain routing and HTTPS delivery.
  • S3 and DynamoDB support image and application data storage.
  • CloudWatch monitoring and budget alerts help track system health and costs.
