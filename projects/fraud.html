Machine Learning Project

Predicting Fraud Transactions

This project applies machine learning to transactional data in order to detect potentially fraudulent activity. It emphasizes rigorous data preparation, class balancing, model evaluation, and practical comparison of learning approaches.

View Report Back to Portfolio

Project Overview

The goal of the project is to build a reliable fraud detection model using real-world style transaction patterns. A strong focus was placed on selecting effective preprocessing and balancing strategies to improve the model’s predictive strength.

  • Analyzed transaction data to predict fraudulent behavior using machine learning pipelines.
  • Applied sampling methods to address class imbalance and improve model training quality.
  • Performed data cleaning and preprocessing to reduce noise and improve generalization.
  • Compared multiple algorithms to determine the strongest-performing model for the task.

Key Features

  • Data exploration and preparation for structured fraud analysis.
  • Use of sampling methods to build a more balanced training dataset.
  • Comparison of Decision Tree, Logistic Regression, and Neural Network models.
  • Evaluation of model performance to guide algorithm choice.
