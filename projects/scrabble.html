Scrabble Game

A browser-based Scrabble game where players build words by dragging letter tiles onto a board, validate plays, and earn points from tile values and board bonuses.

Play the game ↗ View source code ↗

Project overview

This interactive word game brings core Scrabble gameplay to the browser. Players arrange a rack of tiles on the board, submit valid English words, and track the score and remaining tiles as they play.

Key features

  • Drag-and-drop tile placement with horizontal and vertical word play.
  • Word validation and score calculation using tile values and double- or triple-score squares.
  • Blank tiles that can be assigned a letter, plus a 50-point bonus for using all seven tiles.
  • Saved words can be reused to build subsequent plays.
  • Controls to return unplayed tiles, exchange tiles, draw a new rack, and start over.
