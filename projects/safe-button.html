Project overview

Safe Button is a Flask application built around a simple daily check-in workflow. The project explores how the same application idea can be deployed using two different cloud platforms, with each implementation using its own identity, storage, and delivery services.

Cloud implementations

Google Cloud

The main branch contains the Flask check-in app and a Cloud Build workflow. The check-in sends a timestamped email through configurable SMTP settings.

Explore Google Cloud branch ↗

AWS

The AWS branch adds Cognito sign-in and per-user DynamoDB records, with an EKS deployment pipeline built from CodePipeline and CodeBuild.

Explore AWS branch ↗

Architecture diagrams

Key features

  • Simple daily check-in interface with a timestamped confirmation.
  • Email notifications configured through SMTP; the AWS implementation supports Amazon SES.
  • Google Cloud delivery workflow using Cloud Build.
  • AWS authentication with Cognito and user check-in data stored in DynamoDB.
  • Containerized AWS deployment to EKS through a staged CI/CD pipeline.
