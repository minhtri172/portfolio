Java Game Development

Shooting Game

The Shooting Game is an interactive Java-based project where the player controls a character and eliminates a stream of moving enemies. It focuses on game mechanics, object-oriented design, and responsive input handling for a fun, engaging experience.

Play Demo Back to Portfolio

Project Overview

This project was created to explore gameplay programming concepts in a structured, maintainable way. The design emphasizes modular logic, real-time interaction, and clean object-based architecture.

  • Built a browser-free arcade-style game using Java and JavaFX visuals.
  • Implemented responsive controls for player movement and enemy elimination.
  • Applied object-oriented programming principles to manage game entities effectively.
  • Focused on gameplay smoothness, modular state logic, and user engagement.

Key Features

  • Dynamic enemy movement that creates an active challenge experience.
  • Player-controlled actions with clear interaction rules and scoring logic.
  • Game loop structure to create a continuous and responsive play flow.
  • Modular reuse of classes and objects to improve maintainability.
