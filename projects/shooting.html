Project overview

This arcade-style game explores gameplay programming through modular logic, real-time interaction, and object-based design.

Key features

  • Dynamic enemy movement creates an active gameplay challenge.
  • Player controls support responsive movement and actions.
  • A continuous game loop manages gameplay state and interaction.
  • Reusable classes and objects keep the game logic modular and maintainable.
